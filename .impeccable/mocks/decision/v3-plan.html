Local Herdr web portal

You want one browser window that shows Herdr and Dogsled together, so you stop switching between Herdr tabs, Glimpse windows and stray browser tabs. This first version runs only on this Mac (127.0.0.1).

First working version

  1. Dogsled board grouped by repository, with todos.
  2. Herdr agent list with a native agent view. There is no terminal emulator: each agent's conversation is drawn from its transcript.
  3. Send a message to an agent (agent.prompt).
  4. Our own plan mode and plan review with annotations, replacing @plannotator/pi-extension.
  5. Our own interview tool, replacing pi-interview.

Run model

A long-running launchd service on a fixed localhost port. When the portal is down, the tools open a one-shot form in a browser tab.

There is no terminal emulator: each agent's conversation is drawn from its transcript. Paste, drop or add images.
