Typed SQLite state store

Replace the JSON files under ~/.local/state/dogsled/ with one SQLite database. Each table maps to a typed Rust struct, so a bad row fails at load and not at use.

Steps

  1. Add state.sqlite with a schema version table and WAL mode.
  2. Move holds, tickets and items into typed tables, one table per type, keyed by request id.
  3. Import the existing JSON files once, then stop writing them.
  4. Delete the JSON readers after one release.

Risks

  • Two daemons on one host open the same file. WAL mode and one writer task prevent lost writes.
  • A ticket in flight during the import could be read from JSON and written to SQLite twice.
